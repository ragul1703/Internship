# Internship – AI & NLP Tasks

This repository contains four completed internship tasks implemented using Python and Google Colab.  
Each task demonstrates the use of Artificial Intelligence, Natural Language Processing, and pre-trained models.

## ✅ Task 1: Text Summarization
**Description:**  
Extractive text summarization using Natural Language Processing techniques.

**Input:** Paragraph text  
**Output:** Short summarized text  

**Technologies Used:**
- Python
- NLTK
- Google Colab

---

## ✅ Task 2: Speech to Text
**Description:**  
Speech recognition system using a pre-trained Google Speech Recognition model.

**Input:** Audio file (.wav)  
**Output:** Transcribed text  

**Technologies Used:**
- Python
- SpeechRecognition library
- Google Colab

---

## ✅ Task 3: Neural Style Transfer
**Description:**  
Applies artistic style from one image to another using image statistics and computer vision techniques.

**Input:** Content image + Style image  
**Output:** Stylized image  

**Technologies Used:**
- Python
- OpenCV
- PIL
- NumPy

---

## ✅ Task 4: Text Generation
**Description:**  
Text generation system using a pre-trained large language model (Gemini).

**Input:** User prompt  
**Output:** AI-generated text  

**Technologies Used:**
- Python
- Gemini API
- REST API
- Google Colab

> ⚠️ API keys are not included in this repository for security reasons.
